준비물
ChatGPT Plus 이상(월 20달러, 부가세 별도), ChatGPT 데스크톱 앱, 크롬. 크롬에는 일 시킬 구글 계정(드라이브, 지메일, 캘린더)이 로그인돼 있어야 합니다. 우리는 맥에서 확인했습니다.
1. 앱 설치
chatgpt.com에서 ChatGPT 데스크톱 앱을 받아 로그인합니다. 예전 'ChatGPT Classic' 앱에는 이 기능이 없습니다.
2. 크롬 확장
앱 설정 → Computer Use → Chrome에서 설치를 누르면 크롬 웹 스토어의 ChatGPT 확장이 열립니다. 구글 계정이 로그인된 크롬 프로필에 추가하십시오. 설정에 '관리'가 보이면 연결된 것입니다.
3. 파일 허용
영수증, 엑셀처럼 내 컴퓨터 파일을 쓰게 하려면 주소창에 chrome://extensions → ChatGPT 확장 → 세부정보 → '파일 URL에 대한 액세스 허용'을 켜십시오. 메일 정리만 할 거면 건너뛰어도 됩니다.
4. Codex 모드
여기서 막혔습니다. 업무(Work) 모드의 @ 메뉴에는 Chrome이 안 뜹니다. 왼쪽 사이드바에서 Codex로 들어가 새 대화를 여십시오. 모델은 GPT-6.1 Terra, 우리는 추론 High로 돌렸습니다.
5. 시키기
대화창에 @를 치고 목록에서 Chrome을 고른 뒤, 아래 프롬프트를 붙여 넣고 [ ] 칸을 채우십시오. 폴더 경로는 Finder에서 폴더를 고르고 ⌥⌘C로 복사합니다. 크롬 뒤쪽 탭에서 일하니 화면이 그대로여도 진행 중입니다.
