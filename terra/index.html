준비물
ChatGPT Plus 이상(월 20달러, 부가세 별도), ChatGPT 데스크톱 앱, 크롬. 우리는 맥에서 확인했습니다.
1. 앱 설치
chatgpt.com에서 ChatGPT 데스크톱 앱을 받아 로그인합니다. 예전 'ChatGPT Classic' 앱에는 이 기능이 없습니다.
2. 크롬 확장
앱 설정 → Computer Use → Chrome에서 설치를 누르면 크롬 웹 스토어의 ChatGPT 확장이 열립니다. 쓸 크롬 프로필에 추가하십시오. 설정에 '관리'가 보이면 연결된 것입니다.
3. Codex 모드
여기서 막혔습니다. 업무(Work) 모드의 @ 메뉴에는 Chrome이 안 뜹니다. 왼쪽 사이드바에서 Codex로 들어가 새 대화를 열고 @를 치면 Chrome이 있습니다. 모델은 GPT-6.1 Terra를 고르십시오. 우리는 추론 High로 돌렸습니다.
4. 보이게 하기
그냥 시키면 뒤쪽 탭에서 조용히 일합니다. 지켜보려면 프롬프트 끝에 '처음부터 끝까지 브라우저 작업은 전부 크롬 맨 앞 탭에서 내가 지켜볼 수 있게 보이게 하고 진행해 줘'를 붙이십시오.
5. 파일 올리기
내 컴퓨터 파일을 드라이브에 올리게 하려면 주소창에 chrome://extensions → ChatGPT 확장 → 세부정보 → '파일 URL에 대한 액세스 허용'을 켜십시오.
사고 막는 한 줄
메일, 결제, 삭제가 걸린 일에는 '초안만 쓰고, 보내지는 마'를 꼭 붙이십시오. 우리 시험에선 지켰지만, 오픈AI 보고서에는 허락 없이 움직인 비율이 13.75%로 나옵니다.
